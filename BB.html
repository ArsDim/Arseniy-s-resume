Layout Project

Барбершоп

✦ Про проєкт

Це сучасний лендинг для барбершопу, де основний акцент зроблено на стилі, преміальності та зручності для клієнта. Макет розроблений з урахуванням специфіки б'юті-сфери: чіткі прайси, галерея робіт та зручна форма запису.


Працюючи над цим макетом, я приділив особливу увагу адаптивності. Оскільки більшість клієнтів записуються до майстрів через смартфони, я реалізував гнучку сітку на CSS Grid, яка ідеально підлаштовується під будь-який екран, зберігаючи при цьому естетику "темної теми".
